* Una nueva funcionalidad puede ser, por ejemplo:

  • El personaje realiza algún diálogo diferente.
    • Pregunta lo mismo hasata que se acierta.
    • Ofrece repetir una vez terminado el juego.
    • Da alguna pista si lo pides o si te equivocas.
    • Explica la función de cada parte cuando se acierta.
  • El personaje hace algún movimiento cuando se acierta o falla alguna pregunta.
  • Las letras hacen alguna animación:
    • Cuando se posa el ratón y/o se hace clic sobre ellas.
    • Cuando se acierta o falla una pregunta.
