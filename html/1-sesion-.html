Situación de Aprendizaje para alumnado

1ª sesión

Texto

Duración
55 minutos
Agrupamiento
Gran grupo

En esta primera sesión:

  1. Habéis accedido a esta web.
  2. Resolveréis los retos de cada uno de los apartados (podéis repartirlos para acabar antes). 
  3. Descubriréis las características de cada uno de los productos finales que habréis de confeccionar. 
  4. Os repartiréis los productos: uno por persona.
  5. Identificaréis las tareas para cada uno de ellos.
  6. Priorizaréis dichas tareas.
